## Publish on GitHub Pages

1. Copy the contents of this folder into a public repository (or its `docs/` folder).
2. In that repository: Settings > Pages > Deploy from a branch, and pick the branch and folder.
3. The guide opens at `https://<owner>.github.io/<repository>/`.
